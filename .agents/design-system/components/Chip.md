# Chip

Filter chips narrow a list or pick an Ask period.

- Height `control-height-small` (32px) with a 48px hit area. Radius `radius-medium`.
- Off: `border-hairline` in `outline`, text `on-surface-variant`.
- On: `secondary-container` with `on-secondary-container` text and a leading check icon. Set `aria-pressed`.
- Counts sit after the label in `tabular-nums`: "Expired 7".
- Ask periods are single-choice: Today, This week, This month, Last month.
- Member filters can combine: status, plan, owes money (FR-01).
- Gap between chips `spacing-100`.
